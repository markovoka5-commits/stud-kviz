# Студ-квиз — приложение для Windows и Ubuntu/Linux

Эта версия упаковывает викторину в отдельное настольное приложение на Electron.
У одноклассников не будет необходимости устанавливать Node.js, открывать терминал или запускать браузер.

## Что получится

- Windows: установщик `Студ-квиз Setup ... .exe` с ярлыком на рабочем столе.
- Ubuntu/Linux: `Студ-квиз ... .AppImage` (запускаемый файл) и пакет `.deb`.

## Как получить готовые установщики для обеих систем

В проект добавлен GitHub Actions workflow `.github/workflows/build-desktop.yml`.
Он собирает Windows-установщик на Windows runner, а Linux-пакеты — на Ubuntu runner.

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. Откройте вкладку **Actions** в репозитории.
3. Выберите **Build desktop installers** → **Run workflow**.
4. После завершения откройте запуск workflow и скачайте артефакты `stud-kviz-windows` и `stud-kviz-linux`.
5. Передайте одноклассникам только подходящий установщик, не исходный код.

Сборка требует подключения к интернету на стороне GitHub Actions. Самим одноклассникам Node.js и интернет для запуска приложения не нужны.

## Запуск на Ubuntu

- `.AppImage`: разрешить запуск файла в свойствах файлового менеджера и открыть двойным щелчком. Если система попросит FUSE, можно установить пакет `libfuse2`/`libfuse2t64` в зависимости от версии Ubuntu или использовать `.deb`.
- `.deb`: открыть файл через установщик приложений Ubuntu и установить.

## Запуск на Windows

Открыть `.exe` и пройти установку. После неё появится ярлык «Студ-квиз».

Примечание: Windows и Linux используют разные установщики. Один `.exe` не запускается в Ubuntu, а `.AppImage` не запускается в Windows.
