# Студ-квиз

## Запуск на Ubuntu

1. Распакуй папку `маркiz2` на Рабочий стол так, чтобы путь был `~/Desktop/маркiz2`.
2. Дважды нажми `Запустить-Студ-квиз.desktop` и выбери **Allow Launching / Trust and Launch**, если Ubuntu спросит.
3. Скрипт сам активирует Node.js 24 через nvm, при необходимости установит зависимости, дождётся запуска Vite и откроет браузер.
4. Не закрывай окно терминала, пока пользуешься сайтом. Для остановки нажми Ctrl+C.

Если ярлык не запускается, открой терминал и выполни:

```bash
chmod +x ~/Desktop/маркiz2/start.sh ~/Desktop/маркiz2/Запустить-Студ-квиз.desktop
~/Desktop/маркiz2/start.sh
```

Если браузер не открылся автоматически, открой вручную: http://127.0.0.1:5173/

Требуется Node.js 24, установленный через nvm в `~/.nvm`.
